# resume_allowlist.txt -- fields of struct nh_globals that are not in any
# checkpoint blob, not in the player-blob tail and not rebuilt by the load,
# each with the reason it needs no carrying. Checked by
# check_resume_coverage.py; one line per field: name, class, reason.
#
# classes:
#   constant     initialiser data only (per-env because the initialiser takes
#                a per-env address)
#   process      file handles, paths, pid, terminal, window procs: the same
#                in the new process
#   options      option-parsing state, re-applied by the reset's option string
#   display      screen, status line, message window state: redrawn by the
#                ^R render
#   transient    only meaningful inside one command, one monster action or
#                one level generation; dead at a command boundary
#   prompt-only  live only while a prompt is open or the hero is helpless.
#                The engine's checkpoint() refuses those states
#                (CheckpointAtPromptError while a misc flag is set), so a
#                checkpoint never sees them.
